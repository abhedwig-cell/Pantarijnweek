# Data

Deze map bevat alleen gegevens die veilig in de openbare repository kunnen staan.

## Belangrijk

Niet committen:
- leerlingnamen of leerlingnummers
- Magisterexports met persoonsgegevens
- telefoonnummers
- privé-e-mailadressen
- herleidbare personeelsgegevens
- ruwe aangeleverde Excel- of Wordbestanden

Gebruik in publieke tabellen alleen niet-herleidbare IDs. Een eventuele private koppeltabel tussen IDs en echte personen moet buiten deze repository blijven zolang de repository openbaar is.

## 2026

De bestanden in `data/2026` vormen het eerste genormaliseerde invoermodel. Momenteel bevatten ze alleen kolommen en veilige basisstructuur. Inhoud wordt pas toegevoegd nadat de authority en privacy-afspraken zijn bevestigd.
